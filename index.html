Apps Script Belum di-Deploy Ulang (New Deployment) Setiap kali ada perubahan pada kode Code.gs (misalnya setelah menambahkan variabel planBy), Apps Script tidak otomatis memperbarui versi Web App yang aktif. Salin URL tersebut ke dalam variabel GOOGLE_SCRIPT_URL di kode HTML Anda. 2. Gangguan Server / Runtime Google Apps Script Berdasarkan log sistem, server Google Apps Script terkadang mengalami gangguan sementara (server error, JavaScript runtime exited unexpectedly, atau deadline exceeded). Jika ini terjadi: Layanan Google Apps Script di sisi server sedang down atau overload. Solusi: Tunggu beberapa menit, lalu coba lakukan Submit kembali, atau jalankan fungsi doPost secara manual melalui Apps Script Editor untuk memastikan tidak ada syntax error. 3. Masalah Izin Akses (Authorization / Scope) Jika skrip baru dikembangkan atau ada perubahan akses pada spreadsheet, izin eksekusi Google Apps Script mungkin terputus. Solusi: Di dalam Apps Script Editor, jalankan fungsi test (misalnya buat fungsi tes sederhana) lalu tekan Run. Jika muncul pop-up "Authorization Required", klik Review Permissions → pilih akun Google Anda → Advanced → Go to Untitled Project (unsafe) → Allow. 4. Mengecek Error Melalui Konsol Browser Untuk mengetahui penyebab pasti secara spesifik: Buka halaman HTML Anda di browser. Tekan F12 (atau Right Click → Inspect) lalu buka tab Console.
